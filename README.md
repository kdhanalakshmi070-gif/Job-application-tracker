# 💼 Job Application Tracker

A simple and practical **Job Application Tracker** built using **Python and SQLite** to manage job applications efficiently.

## 📌 Project Overview

The Job Application Tracker is a command-line application that allows users to add, view, update, search, and delete job application records.

It also provides a **Dashboard** to view the total number of applications and their current status.

## 🛠️ Technologies Used

* Python
* SQLite
* SQL
* Git & GitHub

## ✨ Features

* ➕ Add new job applications
* 📋 View all applications
* 🔄 Update application status
* 🔍 Search applications
* 🗑️ Delete applications
* 📊 Dashboard with application statistics
* ✅ Input validation
* 💾 SQLite database storage

## 📋 Application Details

Each application stores:

* Application ID
* Company
* Job Role
* Experience
* Qualification
* Application Date
* Status

## 📊 Application Status

Applications can have the following statuses:

* Applied
* Under Review
* Interview
* Selected
* Rejected

## 📊 Dashboard

The Dashboard displays:

* Total Applications
* Applied Applications
* Under Review Applications
* Interview Applications
* Selected Applications
* Rejected Applications

## 🎯 Project Objective

The main objective of this project is to create a simple and practical job application management system using **Python and SQL**.

This project demonstrates:

* CRUD operations
* SQLite database connectivity
* SQL queries
* Input validation
* Application status management
* Basic Python programming concepts

## ▶️ How to Run

1. Clone or open the repository.
2. Make sure Python is installed.
3. Run the following command:

```bash
python3 job_tracker.py
```

4. Select an option from the menu.
