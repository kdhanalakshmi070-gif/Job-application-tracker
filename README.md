# Job Application Tracker

A Python and SQL based Job Application Tracker.

## 📌 Project Description

Job Application Tracker is a simple application developed using Python and SQLite.

This project helps users manage their job applications in one place. Users can add, view, update, search, and delete job applications and also view application statistics through a dashboard.

## 🚀 Features

- Add new job applications
- View all applications
- Update application status
- Search applications by:
  - Company
  - Job Role
  - Status
- Delete applications
- Dashboard with application statistics
- SQLite database integration
- Input validation
- Status validation

## 🛠️ Technologies Used

- Python
- SQLite
- SQL
- GitHub

🗄️ Database

The project uses SQLite to store job application data.

Applications Table
Column	Description
Application_ID	Unique application ID
Company	Company name
Job_Role	Job role
Experience	Experience required
Qualification	Candidate qualification
Application_Date	Date of application
Status	Current application status
▶️ How to Run
1. Clone the Repository
git clone https://github.com/your-username/job-application-tracker.git
2. Open the Project
cd job-application-tracker
3. Run the Python Program
python job_tracker.py

The SQLite database will be created automatically when the program runs.
